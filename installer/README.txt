轻播 Lite 安装说明
==================

1. 安装程序默认安装到当前用户的 %LOCALAPPDATA%\LiteMP4 目录，不需要管理员权限。
2. 安装后可从桌面或开始菜单启动“轻播 Lite”。
3. 首次打开后，点击“打开 ▾”选择视频文件或文件夹，也可将视频拖入窗口。
4. 支持 MP4、MKV、MOV、AVI、WebM 等常见格式；AV1、HEVC 等高分辨率编码会自动使用兼容播放后端。
5. 普通播放、连续播放、多选播放、单曲循环、置顶、播放列表和系统托盘均可在窗口中使用。
6. 安装包包含运行所需的 runtime 文件夹，不需要另行安装 VLC、Python 或 .NET 下载器。
7. 可选 MP4 文件关联在安装时默认不勾选，勾选后双击 MP4 文件将使用轻播 Lite 打开。
8. 卸载可通过 Windows“应用和功能”或开始菜单中的卸载入口完成。
